Dokumen · Cara pakai

  1. Pilih foto.

Foto
Pilih / tarik / tempel
PNG, JPG, atau WEBP (maks 30 MB). Bisa tarik file ke halaman atau tempel dengan Ctrl+V. Sisi terpanjang otomatis diperkecil ke 1200 px agar cepat.
Kartu berkas
Menampilkan thumbnail, nama, ukuran, dan dimensi. Tombol Ganti foto untuk memuat foto lain.

Alat background
Pipet
Ketuk warna latar di foto untuk menghapusnya. Ketuk lagi untuk latar yang banyak warna.
Hapus / Pulihkan
Kuas manual untuk menghapus atau mengembalikan bagian foto. Ukuran kuas 4–120 px.
Urungkan
Membatalkan sampai 12 langkah kuas terakhir.
Reset
Menghapus semua edit kuas manual.
Pengaturan Background
Hapus background
Saklar utama. Latar seragam di tepi foto terdeteksi otomatis saat foto dimuat.
Chip warna (×)
Warna latar yang dipilih. Tekan × untuk melepas satu warna.
Deteksi dari tepi foto
Mengambil sampai 3 warna dominan dari tepi foto sebagai latar.
Lepas semua warna
Mengosongkan semua warna latar.
Toleransi warna (2–70)
Seberapa mirip sebuah warna agar dianggap latar. Naikkan bila sisa latar masih ada, turunkan bila objek ikut terhapus.
Rapikan tepi (0–8 px)
Mengikis tepi objek untuk membuang pinggiran halo atau sisa latar.
Hanya yang tersambung ke tepi foto
Warna sama di dalam objek (misalnya lubang huruf O) tidak ikut terhapus.
Pakai transparansi bawaan PNG
Muncul bila PNG punya area transparan. Area itu dipertahankan sebagai latar.
Trace
Jenis gambar
Preset: Anime/ilustrasi (14 warna), Anime detail (18 warna, line art halus, sampai 400 layer), Anime simple (8 warna, hanya garis utama, ±70 layer), Logo/flat (6), Foto (20), Hitam-putih (2). Mengubah slider apa pun berpindah ke Kustom.
Tangkap line art
Mencari garis tipis gelap (garis rambut, bulu mata, kontur mata) dan membuatnya jadi layer terpisah di atas warna, supaya tidak hilang. Hanya untuk mode warna.
Kepekaan garis (1–10)
Makin besar makin banyak garis yang tertangkap, termasuk garis samar. Turunkan bila tekstur latar ikut jadi garis.
Jumlah warna (2–32)
Banyak warna maksimum di hasil. Lebih banyak = lebih mirip foto, tetapi lebih banyak layer.
Isi bentuk, Ambang, Warna tinta
Khusus hitam-putih. Pilih bagian gelap, terang, atau keduanya. Ambang otomatis memakai metode Otsu; matikan untuk atur manual (10–245). Warna tinta menentukan warna bentuk.
Buang bercak kecil (px²)
Membuang titik kecil. Naikkan untuk hasil lebih bersih.
Buang garis tipis (px)
Membuang area lebih tipis dari nilai ini, berguna untuk sisa artefak JPEG.
Kehalusan kontur
Makin besar makin mulus dan sederhana; makin kecil makin setia pada bentuk asli.
Maksimum layer (10–400)
Batas jumlah shape. Layer lebih sedikit membuat Alight lebih ringan.
Potong lubang transparan
Latar yang terkurung dalam objek menjadi lubang sungguhan. Matikan bila di Alight lubangnya terisi penuh.
Mesin
Otomatis (server, cadangan lokal), Server saja, atau Lokal di perangkat.
Alight Motion
Ukuran scene (200–4000 px)
Sisi terpanjang scene di XML. Bawaan 1440.
Warna latar scene
Warna latar proyek di Alight.
Hasil & unduh
Trace sekarang / Trace ulang
Menjalankan trace dengan pengaturan saat ini. Bilah progres dan status menunjukkan prosesnya.
Pembanding Foto ⟷ Trace
Geser untuk membandingkan foto dengan hasil.
Statistik
Jumlah shape, titik, lubang, mesin yang dipakai, waktu, dan ukuran scene. Muncul peringatan bila layer lebih dari 250.
Unduh SVG / Unduh XML Alight
SVG untuk editor vector. XML untuk diimpor ke Alight Motion.
Chip Server
Menunjukkan server siap atau tidak. Bila tidak, trace berjalan di perangkat.
